# Lectio — фронтенд

React 19 + TypeScript + Vite. Данные — TanStack Query, роутинг — React Router,
конспекты — react-markdown с формулами KaTeX, иконки — lucide.

## Запуск

Нужен запущенный бэкенд на `127.0.0.1:8000` (см. README в корне). Dev-сервер
проксирует `/api` туда, поэтому cookie с refresh-токеном работает без CORS.

```bash
npm install
npm run dev          # http://localhost:5173
npm run typecheck
npm run build        # dist/client
```

Другой адрес API: `LECTIO_API_TARGET=http://host:8000 npm run dev`.

Не смешивайте `localhost` и `127.0.0.1` в одном сеансе: у них разные cookie,
и вход «пропадёт».

## Что где

```text
src/
├── api/          # типы ответов, fetch-клиент с обновлением токена, хуки запросов
├── auth/         # контекст пользователя: вход, регистрация, восстановление сессии
├── components/   # оболочка с сайдбаром, карточки, Markdown, примитивы UI
├── pages/
│   ├── lecture/  # страница лекции: плеер, расшифровка, вкладки, чат, курс
│   └── …         # главная, каталог, курсы, поиск, избранное, заметки, загрузка, профиль
├── lib/format.ts # таймкоды, длительности, склонения
└── styles/       # дизайн-токены и стили
```

## Страница лекции

- Собственный плеер: субтитры поверх видео из расшифровки, засечки глав и
  закладок на полосе перемотки, скорость, полный экран.
- Горячие клавиши: `Пробел`/`K` — пауза, `←`/`→` — 5 с, `J`/`L` — 10 с,
  `C` — субтитры, `M` — звук, `F` — полный экран, `B` — закладка.
- Расшифровка подсвечивает текущую фразу и прокручивается за видео; клик по
  фразе, разделу оглавления, термину или цитате в ответе AI перематывает видео.
- `?t=секунды` в адресе открывает лекцию с нужного момента — так работают
  результаты поиска и кнопка «Поделиться».
- Позиция просмотра сохраняется каждые 10 секунд и на паузе; при следующем
  открытии лекция продолжается с того же места.
- Пока лекция обрабатывается, страница сама опрашивает статус и показывает этапы.

`worker/`, `scripts/`, `.openai/` и `tests/sites-worker.test.mjs` — обвязка для
хостинга Sites, `npm run build` готовит под неё `dist/`.
