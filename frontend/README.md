# Lectio frontend

Русский интерфейс Lectio на React 19 и Vite, по композиции [Mentora Learning Dashboard](https://dribbble.com/shots/26474286-Mentora-AI-Powered-Learning-Dashboard) (Miawmiaw). Контракты интеграции — `../BACKEND_API.md`. Бэкенд и его настройки не изменяются.

## Запуск

Нужен Node.js 22.12+ (проверено на 24). Из этой папки:

```bash
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5173. API должен работать на `http://127.0.0.1:8000`. Vite проксирует `/api` на бэкенд: JSON, видео, VTT, аватары и HttpOnly-cookie используют один origin. Для другого адреса API:

```bash
LECTIO_API_TARGET=http://127.0.0.1:8001 npm run dev
```

Не смешивайте `localhost` и `127.0.0.1` в одном сеансе: у них разные cookie. `Secure` для refresh-cookie должен соответствовать локальному HTTP-окружению (см. справку бэкенда). Установленные библиотеки и шрифт включаются в сборку, внешние CDN не нужны.

## Что реализовано

- Просмотр лекции: реальное видео с Range, скорость, звук, полный экран, VTT-субтитры; сохранение и восстановление позиции, явное завершение.
- Безопасный Markdown-конспект, главы и подразделы, скачивание `.md`, расшифровка с фильтром, ключевые термины. Все таймкоды перематывают один плеер.
- Смысловой поиск по лекции, курсу и всей базе; переход из выдачи к нужному моменту.
- Q&A с историей, источниками-таймкодами, состояниями ожидания, ошибки и отмены. История ограничена контрактом API и живёт в состоянии текущей лекции.
- Вход/регистрация, роль, восстановление сессии, один общий refresh для параллельных запросов, выход, профиль и аватар.
- Личный дашборд, мои курсы, запись и отписка, избранное, закладки с созданием, изменением и удалением.
- Преподаватель: свои материалы, создание курса, импорт ссылки/загрузка файла, переименование и перенос лекции, повторная обработка и генерация конспекта, удаление с подтверждением. Доступность действий определяют роль и `can_manage`.
- Каталог, фильтры по названию и статусу, обработка пустых состояний и ошибок, polling активной обработки раз в 4 секунды на видимой странице.
- Адаптивная компоновка, мобильное меню, фокус и клавиатура модальных окон, `Cmd/Ctrl+K` для поиска.

Начальная страница — явно помеченный **демо-курс**, чтобы можно было посмотреть оформление независимо от наполнения сервера. Его расшифровка, AI-ответ и конспект — примеры; видео отсутствует, кнопка воспроизведения предлагает перейти в библиотеку. Только демо-избранное и демо-заметки хранятся в `localStorage` с ключом `lectio:demo`. Они не смешиваются с данными сервера. Настоящая библиотека открывается через «Каталог лекций» или «Перейти к настоящим лекциям».

Ссылки имеют вид `/#/lecture/<uuid>?t=123`. Их можно открывать напрямую и копировать с текущим таймкодом. Локальные ссылки доступны только на этом компьютере.

## Проверки и сборка

```bash
npm test
npm run build
```

`npm test` проверяет поведение API-клиента при ротации refresh-cookie, параллельных 401, multipart/204, сетевом сбое создания и бизнес-ошибках. Результат сборки — `dist/client`. Для production раздавайте эту директорию и проксируйте `/api` на Lectio. `npm run preview` — только просмотр сборки; production reverse proxy настраивается отдельно. Шаблон содержит также необязательную инфраструктуру Sites; публикация не выполнялась.

## Ограничения текущего среза

Каталог и список курса загружают первые 200 лекций (максимум страницы API); при большем каталоге требуется пагинация. Редактирование и удаление курса, очистка истории, смена пароля/email и серверное сохранение чатов в этот интерфейс не входят. При загрузке файла показана передача без точного процента; прогресс последующей обработки относится к **текущему этапу**. Перегенерация конспекта подтверждает приём задачи, но не обещает её завершение по первому старому `ready`.
