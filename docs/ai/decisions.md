# Решения

Формат: решение — почему — что отвергли.

## Бэкенд

- **FastAPI + async SQLAlchemy + Postgres/pgvector, стиль linkup.** Пользователь
  так пишет, векторы и полнотекст в одной БД, каскадное удаление чистит индекс.
  Отвергли: Qdrant/Chroma (лишний сервис), Elasticsearch.
- **Своя очередь на Redis-списке.** arq несовместим с redis 8, Celery избыточен.
- **Гибридный поиск + RRF.** Векторы промахиваются на точных терминах,
  полнотекст — на перефразировках. RRF не требует подбора весов.
- **BGE-M3.** Лучший доступный многоязычный, кроссязычный поиск бесплатно.
- **faster-whisper large-v3-turbo int8; на Mac mlx-whisper.** Turbo — баланс
  скорости и точности; ~20× реального времени на 1660 Super.
- **Реплики из пословных таймкодов.** Batched Whisper даёт сегменты по 20–30 с —
  непригодно для субтитров.
- **Конспект best effort.** Без LLM лекция всё равно ищется и смотрится.
- **Тест по запросу, а не в конвейере** (27.10): работает для уже
  обработанных лекций без переобработки, не удлиняет конвейер. Отвергли
  генерацию в воркере после конспекта.
- **Тест составляет преподаватель один раз** (27.10, просьба пользователя):
  студенты проходят один и тот же тест, иначе статистика бессмысленна.
  Хранится только последняя попытка — для демо и «кто что ответил» хватает.
- **Геймификация без своих таблиц** (27.10, накануне защиты): всё
  выводится из существующих данных — ноль миграций, нельзя рассинхрониться,
  у демо-аккаунтов сразу есть прогресс. Цена — пересчёт по всем
  пользователям на каждый запрос рейтинга (на десятках пользователей
  незаметно, на тысячах нужен кеш). Преподаватели не ранжируются.
- **Бот ходит в сервисы напрямую, а не через HTTP API** (27.10): нет
  служебного аккаунта и токенов, переиспользуется тот же код; цена — бот
  держит свою копию BGE-M3 и подключение к БД.
- **aiogram 3 требует pydantic < 2.14** — откатились с 2.14.1 на 2.13.5,
  тесты зелёные.
- **Агрегатная статистика лекции публична**, детальная (имена в тесте) —
  только преподавателю.
- **Варианты теста перемешивает сервер**, модель отдаёт верный ответ текстом:
  индекс от маленькой модели путается (0/1-based) и смещён к первому варианту.
- **Валидация до очереди** (ffprobe для файлов, yt-dlp без скачивания для
  ссылок) с машинными кодами ошибок.
- **MinIO/S3 за переключателем, local по умолчанию** (27.10, просьба
  пользователя накануне защиты): демо не зависит от нового кода. Отдача
  редиректом на подписанную ссылку, а не проксированием через API: бакет
  сам отдаёт Range, API не гоняет гигабайты. Образ `pgsty/minio` —
  официальные образы MinIO закрыты (docker.io и quay.io отдают denied).
- **Видео/субтитры/превью публичны.** `<video>` не умеет `Authorization`.
  Позже — подписанные ссылки.
- **Роль выбирается при регистрации.** Удобно для демо; в реальности — инвайты.

- **Дубли — предупреждение, а не запрет** (28.10): одна и та же лекция
  обрабатывается один раз, остальные открывают готовую («торрент
  результатов, а не мощностей»). Ключ ссылки берём у yt-dlp
  (`extractor_key:id`), а не парсим URL сами — так работают все сайты.
  Похожие, но не одинаковые файлы (перекодированные) не ловим: для этого
  нужно сравнивать расшифровки после обработки.
  Атомарность — advisory-блокировкой на транзакцию, а не уникальным
  индексом: «всё равно добавить» законно создаёт дубль, индекс бы мешал.

- **Глоссарий без своей таблицы** (28.10): собирается из
  `lectures.key_terms` на каждый запрос, поэтому всегда совпадает с
  конспектами и не требует фоновой синхронизации. Для десятков лекций это
  миллисекунды; на тысячах лекций понадобится материализованная таблица.

## Видеопамять (6 ГБ на всё)

- BGE-M3 грузится сразу в fp16; поиск в API на CPU (`SEARCH_DEVICE=cpu`),
  чтобы LLM влезала целиком: 68 vs 39 ток/с.
- Воркер выгружает модели между этапами и просит Ollama выгрузить свою.
- Ollama: flash attention + q8 KV-кеш.

## Фронт

- **Переписан с нуля** (26.10): версия кореша подмешивала демо-данные в
  настоящие лекции и была одним компонентом на 2300 строк.
- **Дизайн «Учебный плакат»** (27.10, выбор пользователя из трёх вариантов);
  первая версия «под Mentora» была «слишком зализанная, нейронкой нарисованная».
- **Свой плеер**, а не нативные контролы: субтитры, главы, закладки, громкость.
- **Превью — JPEG с сервера**, а не `<video #t=8>` в карточках (тормозило).

## Процесс

- Коммиты вне слотов хакатона не прятать, даты не переписывать: в правилах
  запрета нет, подмена хуже вечерних коммитов.
- Коммитит пользователь сам; агент коммитит/пушит только по прямой просьбе.
  Стиль сообщений: conventional commits (`feat:`, `feat(frontend):`).
