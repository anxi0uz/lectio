# docs/ai — память проекта для AI-агентов

Эта папка — общий контекст для Claude, Codex и любых других агентов, которые
работают в репозитории. Её пишут и поддерживают сами агенты, чтобы новая
сессия не восстанавливала всё заново из истории чата.

| Файл | Что внутри | Когда обновлять |
|---|---|---|
| [project.md](project.md) | Что это за проект, хакатон, ТЗ, критерии, сроки, команда | Меняются цели, сроки, состав или договорённости |
| [architecture.md](architecture.md) | Как устроены бэкенд, воркер, фронт, данные; как запускать; соглашения по коду | Меняется структура, стек, запуск, соглашения |
| [decisions.md](decisions.md) | Принятые решения и почему именно так | Приняли новое решение или пересмотрели старое |
| [gotchas.md](gotchas.md) | Грабли, на которые уже наступили, и как их обходить | Нашли новую неочевидную проблему |
| [status.md](status.md) | Что сделано, что в работе, что дальше, открытые вопросы | **После каждого законченного куска работы** |

Правила:

- Пишем по-русски, коротко, фактами. Это рабочие заметки, а не документация
  для людей: README проекта лежит в корне.
- Только то, чего нельзя быстро вывести из кода. Не копировать код и списки
  эндпоинтов — для этого есть `/docs` (OpenAPI) и README.
- Даты абсолютные (`27.10.2026`), не «вчера».
- Устаревшее удалять или исправлять, а не дописывать рядом противоречие.
