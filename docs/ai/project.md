# Проект

**Lectio** — веб-сервис для смыслового поиска по видеолекциям. Решение кейса
хакатона «Киберрывок 2026» (основной этап), организатор ФЦПТ СПбГУ.

## Кейс (ТЗ, кратко)

Веб-приложение, чтобы студенты и преподаватели:

1. загружали видео (MP4, WebM) или ссылки (YouTube, Vimeo), видео хранится с
   уникальным id, аудио извлекается автоматически;
2. получали расшифровку (Whisper/Vosk) и семантический индекс (эмбеддинги),
   таймкоды фрагментов с точностью до секунды;
3. искали по смыслу: результат — фрагмент, таймкод, ссылка на момент видео;
4. смотрели видео со встроенным плеером: переход по таймкодам, субтитры
   синхронно с видео, клик по тексту перематывает;
5. получали конспект (LLM), структуру лекции с разделами и подразделами,
   оглавление с переходом к разделу.

Доп. фишки из ТЗ (по желанию): поиск по курсу, чат по лекции, ключевые термины,
импорт по ссылке, офлайн-режим. Организатор в чате подтвердил: личный кабинет
тоже засчитывается как фишка. Ограничений по языку и загрузке нет,
«валидация приветствуется».

## Критерии жюри

Функциональность · удобство · качество смыслового поиска · стабильность ·
доп. фишки · презентация и защита (живая демонстрация).

Сдать: рабочий прототип, Git-репозиторий, краткую документацию по запуску,
презентацию со скриншотами.
